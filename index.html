Crypto-only swing-trade research: candle signals, a volatility-sized stop/target for every coin, a probability projection, and a place to discover coins beyond your list. No API key, no signup — CoinGecko's free public data, used as-is.

Get started

1. Add a coin in Watchlist (symbol like BTC, or a full name).

2. Hit Refresh all — every coin gets a technical score and a suggested stop/target.

3. Use Discover to browse coins by category you might not already know, or Analyzer for a deep dive with the probability projection.
